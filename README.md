# Init
1. `cargo install --path .`

# Usage

Use with `plugin-cli [COMMAND] [OPTIONS]` example `plugin-cli create` creates a new Plugin Repo.

# Commands
| Command     | Description                                               |
| ----------- | --------------------------------------------------------- |
| **create**  | Initialize code for a plugin                              |
| **package** | Package the plugin into a distributable package           |
| **publish** | Publish Package on NPM (WIP)                              | 
|  **help**   | Print this message or the help of the given subcommand(s) |

| Option            | Description                                               |
| -----------       | --------------------------------------------------------- |
| **-h, --help**    | Prints this Tables in the Console                         |
| **-v, --version** | Shows the current SemVer of this Package                  |
